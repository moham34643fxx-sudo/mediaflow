# Controlled AV1 validation fixture

`av1-validation.mp4` is generated by `tools/generate_av1_validation_fixture.py`
using synthetic moving test frames and a sine wave. It contains 16 AV1 frames
(128×96, 8fps, 2 seconds) and AAC audio. It is test-APK data, not production media.

The corruption regression preserves the MP4 index and first frames, then damages
only late video packets. A first-frame check is deliberately insufficient.
